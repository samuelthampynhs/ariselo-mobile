# Ariselo mobile

Ariselo's phone app for **iPhone and Android**, in Flutter: one codebase, two apps. It talks to
the same API as the website, at **https://dev.ariselo.co.uk** by default. The website and
backend are in [ariselo-app](https://github.com/samuelthampynhs/ariselo-app), the AWS side in
[ariselo-infra](https://github.com/samuelthampynhs/ariselo-infra).

## What's in it

**Grown-ups**
- Log in (with the two-step code when it's on), start a free trial, reset a password
- The family: the family code, every child, add / change / remove a child (name, year group,
  picture, PIN)
- A child's progress: last 30 days, the last 14 days as a chart, Maths and English, latest answers
- **Start [child]**: hands the phone to that child, already signed in
- Plan: trial, monthly or yearly through Stripe (opens in the browser), change card or cancel
- Settings: sign out, sign out on every device; account and data pages open on the website

**Children**
- Family code → tap your picture → 4-number PIN (the code is remembered on the phone)
- Learning: today's practice, skills, lessons, mock tests and stars. For now these are the
  website's own child pages shown inside the app with the child's session, so questions,
  marking and stars are the same everywhere. "I'm done" signs the child out. On Android the
  back button steps back through the lessons before leaving.

## Get the apps without building anything

- **Android:** every push to main builds it. **Actions → CI → the latest run → Artifacts →
  ariselo-android** has `app-release.apk`: copy it to an Android phone and open it (allow
  "install unknown apps" once). It's signed with a test key, fine for trying, not for Google Play.
- **iPhone:** **Actions → CI → Run workflow** (leave "Build the iPhone app" ticked). The run keeps
  `Ariselo-simulator.zip`, which opens in Xcode's Simulator on a Mac. A real iPhone needs signing
  (below).

## Work on it

You need Flutter (stable). iPhone builds also need a Mac with Xcode; Android builds need Android
Studio or the Android SDK and Java 17.

```bash
scripts/platforms.sh                 # makes ios/ and android/ (once)
flutter pub get
flutter run                          # dev.ariselo.co.uk
flutter run --dart-define=ARISELO_URL=https://ariselo.co.uk   # prod, once it is live
flutter test
```

`ios/` and `android/` are generated by `scripts/platforms.sh` (and ignored by git) until someone
commits them from a Mac. Only `lib/`, `test/` and `pubspec.yaml` are hand-written.

## Before the stores

| | Apple App Store | Google Play |
|---|---|---|
| Account | Apple Developer Program, £79 a year | Play Console, $25 once |
| Signing | certificate and profile; App Store Connect API key as a GitHub secret | an upload key (keystore) as a GitHub secret |
| Children | "Kids" category rules: no third-party ads or analytics, a parental gate before links out or payments | "Designed for Families" / Families policy: the same spirit, plus a target-age declaration |
| Payments | selling the subscription inside the app means in-app purchase; showing a plan bought on the web and linking to manage it needs care with App Review | Google Play Billing for in-app sales; same question |

The Plan screen and links out are only in the grown-ups' part; the children's part keeps them
inside /learn.

natively in the app, so practice works offline and feels fully native.
